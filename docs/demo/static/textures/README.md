# Console housing material

`cassette-shell.webp` is a 512×512 self-hosted material tile generated with the built-in ImageGen tool. It is used only on the beige hardware housings; text, controls, screws, indicators and financial values are live HTML/CSS.

The source raster was converted and resized in the existing remote Pillow environment. No runtime image service or external font request is needed.

Generation prompt:

> Use case: productivity-visual. Asset type: subtle seamless raster material tile for UI hardware housing, not a mockup. The prior image is STYLE REFERENCE ONLY for the matte beige plastic case. Generate a square perfectly flat top-down uniform material texture of aged warm beige molded ABS plastic, base color #BDB49C to #C5BDA7. Extremely subtle fine-grain molded plastic pores and faint authentic decades-old patina/speckling, tiny superficial scuffs. Very even diffuse ambient illumination, no directional shading, NO visible highlights or gradients, NO shadows. Must tile seamlessly on all edges and read as quiet neutral beige when tiled at 350px. NO objects, NO hardware, NO screws, NO borders, NO edges, NO text, NO markings, NO labels, NO badges, NO panels, NO design layout or typography. This is a repeatable quiet material texture only. Very low contrast, not distressed, not dirty, not concrete, not wall, not marble.
