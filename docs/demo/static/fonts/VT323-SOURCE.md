# VT323 numeric readout font

VT323 Regular (400) is self-hosted for the cassette console's pixel-like numeric readouts. The existing IBM Plex Mono and system Chinese fonts remain fallbacks for UI labels and unsupported characters.

Retrieved 2026-10-28 from the official Google Fonts repository:

- Font: https://raw.githubusercontent.com/google/fonts/main/ofl/vt323/VT323-Regular.ttf
- License: https://raw.githubusercontent.com/google/fonts/main/ofl/vt323/OFL.txt

The unmodified font binary is distributed with its complete SIL Open Font License 1.1 in `OFL-VT323.txt`.

Validation through the existing remote fontTools package: family `VT323`, weight `400`; digits: covered; uppercase: covered; colon: covered; dollar: covered; yen: covered; euro: covered. All ten digits have the same advance width (400 font units). No dependencies were installed.
