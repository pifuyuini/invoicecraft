# IBM Plex Mono UI font

IBM Plex Mono Regular (400) and SemiBold (600) are bundled for the console interface. They are self-hosted; the browser does not request a font CDN. Simplified Chinese remains covered by the existing system/Noto fallback.

Retrieved 2026-10-28 from the official Google Fonts repository:

- https://github.com/google/fonts/blob/main/ofl/ibmplexmono/IBMPlexMono-Regular.ttf
- https://github.com/google/fonts/blob/main/ofl/ibmplexmono/IBMPlexMono-SemiBold.ttf
- https://github.com/google/fonts/blob/main/ofl/ibmplexmono/OFL.txt

License: SIL Open Font License 1.1; copyright notice and full license are preserved in `OFL-IBM-Plex.txt`. The license allows embedding and redistribution. These files are unmodified upstream font binaries.

Validation: both fonts loaded successfully using the existing fontTools package; family, weight and character maps were inspected. No dependencies were installed.
